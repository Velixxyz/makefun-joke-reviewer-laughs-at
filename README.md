# The joke the reviewer laughs at

Entry for the make.fun bounty `the-joke-the-reviewer-laughs-at-20261121-0329`.

`main.py` (Python 3.13, standard library only, no network) writes one
one-line joke about working beside AI coding agents to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Run it:

```sh
python3 main.py
```
